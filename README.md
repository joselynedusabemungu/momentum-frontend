# Momentum Frontend

The frontend application for **Momentum**, an AI-powered progress intelligence platform designed to help users set goals, manage tasks, track progress, and receive contextual AI-assisted guidance.

Built with **Next.js, React, and TypeScript**, the application provides the user-facing interface for interacting with Momentum's backend services.

---

## Overview

Momentum brings together a user's goals, tasks, activities, assessments, and progress data to create a more contextual view of personal development.

The frontend provides the interface through which users can:

- Create and manage their account
- Complete onboarding
- Set and manage goals
- Create and manage tasks
- Track their progress
- View assessments and progress information
- Interact with AI-assisted features
- Receive notifications
- Manage their account and settings

The frontend communicates with the Momentum backend through REST APIs, allowing application data and business logic to remain centralized in the backend.

---

## Key Features

### Authentication

The application provides user authentication flows including:

- User registration
- User login
- Authenticated sessions
- Protected application pages
- Authentication state management

Authentication requests are handled through the Momentum backend API.

---

### Onboarding

New users complete an onboarding flow after registration.

The onboarding experience collects the information required to personalize the user's Momentum experience.

Once completed, users can proceed to the main application.

---

### Dashboard

The dashboard provides an overview of the user's Momentum activity.

It brings together relevant information such as:

- Goals
- Tasks
- Progress
- Activity
- Recommendations

This provides users with a central location from which they can navigate their progress journey.

---

### Goals

Users can create and manage goals that represent the outcomes they want to achieve.

The frontend retrieves and updates goal information through the backend API.

---

### Tasks

Tasks represent actionable steps that contribute toward a user's goals.

Users can:

- View tasks
- Create tasks
- Update tasks
- Track task completion
- Manage task-related information

Task state is persisted through the backend.

---

### Progress Tracking

Momentum presents users with information about their progress over time.

Progress data is retrieved from backend services and presented through the frontend interface to help users understand their activity and development.

---

### Assessments

The application includes assessment-related functionality for collecting structured information about a user's progress and needs.

Assessment information can contribute to the broader personalization and AI-assisted experience.

---

### AI-Assisted Experience

Momentum integrates AI into the broader application experience rather than treating AI as an isolated chatbot.

The frontend provides interfaces through which users can access AI-assisted functionality based on relevant application context.

This context can include information such as:

- Goals
- Tasks
- Activity
- Progress
- Assessments
- Previous interactions

The backend is responsible for processing this information and communicating with the relevant AI services.

---

### Notifications

The frontend provides users with access to relevant notifications generated by the Momentum backend.

Notifications allow the application to communicate updates and other relevant information to users.

---

### Settings

Users can manage account-related functionality through the settings area.

Settings functionality communicates with backend services where account data or authenticated operations are required.

## Run

```bash
npm install
npm start
```

The development server runs on http://localhost:3000 and proxies API requests to FastAPI at http://localhost:8000.

TanStack Query manages server state and TanStack Form manages forms.
